# RSP OBD2 — 자동차 OBD2 스캐너 (안드로이드)

ELM327 호환 OBD2 어댑터(WiFi · 블루투스 · BLE)로 차량 데이터를 실시간으로 보고, 기록하고, 분석하는 안드로이드 앱입니다.
전기차(현대·기아·제네시스 등) 배터리 정보에 특화되어 있습니다.

## 📥 다운로드

**[⬇ 최신 APK 다운로드](https://github.com/seatoskymee/RSP-OBD2-Release/releases/latest/download/RSPOBD2_latest.apk)**

- 모든 버전: [Releases](https://github.com/seatoskymee/RSP-OBD2-Release/releases)
- 설치: 다운로드한 APK 실행 → "출처를 알 수 없는 앱 설치" 허용 (디버그 빌드)
- 요구 사항: Android 8.0 이상
- **어댑터가 없어도** 첫 화면의 [데모로 미리 체험하기] 로 가상 차량의 모든 화면을 둘러볼 수 있습니다.

## 주요 기능
- **연결**: 상단 [연결] 메뉴 — WiFi 자동 연결(IP 몰라도 됨) · 블루투스(클래식 SPP · BLE 한 목록) · IP 직접 연결.
  OBD 어댑터로 보이는 이름만 목록에 표시, 연결 후 자동 페어링. KONNWEI KW901 · Vgate 계열 BLE 어댑터 지원
- **실시간**: 다이얼 게이지 + 추이 그래프, 차량이 지원하는 표준 OBD-II 항목 전부. 충전 중에는 충전 전력·충전량·배터리 잔량 증가 표시
- **차량 상태**: 배터리 잔량(SOC) · 배터리 건강도(SOH) · 셀 전압(격자) · 온도 · 12V · 급속/완속 충전 · 타이어 공기압 · 문/잠금 그림. 화면을 아래로 끌면 새로 고침
- **고장코드**: 확정/대기 고장코드 조회 · 삭제, 차대번호(VIN)
- **제어**
  - 차량 진단: 표준·제어기별 고장코드, 제어기 응답, 배터리·12V, 충전, 타이어를 한 번에 점검
  - 제어기별 고장코드: 표준 조회에 나오지 않는 제조사 전용 코드를 제어기마다 직접 조회, 응답하는 제어기 주소 검색
  - 차량 명령(코나 일렉트릭 · 니로 EV): 문 잠금/해제, 사이드미러, 방향지시등, 뒷유리 열선 — **실차 검증 전**
- **리포트 (PDF)**: 전체 진단 결과를 A4 로 저장·공유 — 항목마다 측정 결과 · 판단 기준 · 평가 소견, 개별 셀 전압 막대
- **고장 상담**: 증상별 점검 안내(인터넷 없이 동작), 차종 + 증상 + 고장코드로 인터넷 사례 검색
- **누적 데이터**: 차량 연결 중 자동 저장(최대 10년), 차량별(차량 번호 + 별명) 분리
  - 게이지를 누르면 기간별 상세 분석 · 조건 필터(주행/충전/급속/완속) · 기간 비교 · 겹쳐 보기 · CSV 내보내기
  - 차량 컨디션: 배터리 건강도 · 셀 편차 · 12V · 전비 추세, 급속 충전 곡선 비교, 셀 전압 추세
- **12V 경고**: 연결 중 12V 보조배터리 전압이 낮으면 알림
- **MQTT · Home Assistant**: 센서 자동 등록
- **주행·충전 기록**: CSV 저장 · 공유

## 지원 차종 (제조사 확장 데이터)
현대 코나 일렉트릭 · 아이오닉 5/6/9 · 아이오닉 일렉트릭, 기아 니로 EV · 쏘울 EV · EV6, 제네시스 GV60 · GV70 전동화 · G80 전동화,
쉐보레 볼트 EV, KGM 토레스 EVX, BYD 아토3 · 씰 등 — 그 밖의 차량은 표준 OBD-II 항목으로 동작합니다.
(차종 데이터는 공개 자료 기반이며 실차 검증 전 항목이 포함되어 있습니다)

## WiCAN 어댑터 BLE 사용
WiCAN 은 BLE 가 기본으로 꺼져 있습니다 → [연결] → WiFi 자동 연결로 먼저 연결 → [연결] 메뉴의 **WiCAN BLE 켜기** → 재부팅 후 [연결] → **블루투스 연결** → 페어링 PIN(기본 123456) 입력.
